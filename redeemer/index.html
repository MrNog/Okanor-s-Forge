Options /redeemer ui

Pick where it talks.

Say, Party, Raid or Whisper, from the minimap button or a slash command.

  • Battle rezzes (Rebirth, Raise Ally, jumper cables, soulstone) always go to raid chat
  • Draggable minimap button that opens the options window
  • /redeemer say|party|raid|whisper to toggle a channel

Install in a minute.

Works on its own; no other addon needed.

  1. Download the zipAlways the latest release, straight from GitHub.
  2. Extract it into AddOnsWorld of Warcraft\Interface\AddOns\Redeemer
  3. Start the gameResurrect someone.
