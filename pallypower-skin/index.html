Every class button on the bar carries a coloured left edge.

Install.

The skin turns off the ElvUI AddOnSkins skin for PallyPower, so the two don't fight.

  1. Install PallyPowerThe skin changes its look, it doesn't replace it.
  2. Extract the skin into AddOnsWorld of Warcraft\Interface\AddOns\PallyPower_Skin
  3. Start the gameA full restart, so the new textures load.
